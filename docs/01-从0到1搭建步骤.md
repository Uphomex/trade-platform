# 01-从0到1搭建步骤

> 面向第一次在本地跑「Spring Boot + Vue + Docker」的同学，按顺序做即可。

## 前置条件

1. 安装 **JDK 17**（`java -version` 能看到 17 即可）。  
2. 安装 **Maven 3.9+**（`mvn -version`）。  
3. 安装 **Node.js 18+** 与 **npm**。  
4. 安装 **Docker Desktop**（Windows/Mac）或 Linux 上的 Docker Engine，并确保 `docker compose` 可用。

## 第一步：获取代码

若你从本仓库克隆：

```powershell
git clone <你的仓库地址>
cd trade-platform
```

## 第二步：启动数据库与中间件

在 `trade-platform` 根目录执行：

```powershell
docker compose up -d
```

等待容器健康后：

- MySQL：`127.0.0.1:3306`，库名 `trade_db`，用户 `trade` / 密码 `trade123`（见 `docker-compose.yml` 与 `schema.sql`）。  
- Redis：`127.0.0.1:6379`  
- RocketMQ NameServer：`127.0.0.1:9876`  
- RocketMQ Broker：`10911` 等端口映射  
- Seata Server：`127.0.0.1:8091`

> 若 RocketMQ 在 Windows 下消费异常，请阅读 `README.md` 中关于 `brokerIP1` / `host.docker.internal` 的说明，并视情况调整 Broker 向客户端宣告的地址。

## 第三步：初始化数据库表

本仓库已在 **MySQL 首次初始化**时自动挂载 `backend/src/main/resources/db/schema.sql`。若你本地已有同名库且需手工重建，可在客户端中执行该脚本全文。

## 第四步：启动后端

```powershell
cd backend
mvn spring-boot:run
```

看到日志中出现 Spring Boot 启动完成、端口 `8080` 监听即可。

**常见问题**

- **连不上 MySQL**：确认 Docker 已启动、`3306` 未被本机其他 MySQL 占用。  
- **连不上 Seata**：确认 `seata-server` 容器已启动；或临时加参数 `--seata.enabled=false` 做纯排障（分布式事务演示会关闭）。  
- **RocketMQ 连接失败**：确认 NameServer/Broker 已启动，且 `application.yml` 中 `rocketmq.name-server` 与本地一致。

## 第五步：启动前端

新开一个终端：

```powershell
cd frontend
npm install
npm run dev
```

浏览器打开终端里提示的地址（一般为 `http://127.0.0.1:5173`）。前端通过 Vite 代理把 `/api` 转发到 `http://127.0.0.1:8080`。

## 第六步：走一遍演示

1. 首页选商品 → 加入购物车 → 结算 → 得到订单号。  
2. 进入订单详情 → 点击「模拟支付成功」。  
3. 等待约 1～3 秒（MQ 消费）→ 刷新订单状态，应最终变为 `COMPLETED`。  
4. 在「订单管理」页筛选不同状态。  
5. 对 `COMPLETED` 订单在详情页发起「申请退款」，观察状态与库存（可在 MySQL 中查看 `trade_sku`）。

## 生产构建（可选）

```powershell
cd frontend
npm run build
```

静态资源输出在 `frontend/dist/`，可由 Nginx 等托管；此时需把反向代理指向后端 API。
