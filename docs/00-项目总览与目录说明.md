# 00-项目总览与目录说明

## 这个项目是做什么的？

`trade-platform` 是一个**教学向**的电商交易演示系统：你可以走完「浏览商品 → 下单（预占库存）→ 模拟支付 → 异步确认库存与 mock 发货 → 完成 → 售后退款」的完整链路。代码刻意保持**单 Spring Boot 应用**，用**包名**表达「订单中心 / 支付中心 / 库存中心 / 履约中心」的职责边界，而不是一上来拆成很多可独立部署的微服务——这更符合很多团队从单体演进的现实路径。

## 技术栈一览

| 组件 | 作用 |
|------|------|
| Spring Boot 3 + Java 17 | Web、事务、定时任务、配置 |
| MySQL + MyBatis-Plus | 订单、商品、库存、支付幂等、物流单、Seata `undo_log` |
| Redis | 订单详情缓存、支付回调 IP 限流、秒杀 Lua 原子扣减演示 |
| RocketMQ | 订单支付后异步：库存确认 + 发货通知（Topic 演示） |
| Seata AT | 下单时「写订单 + 预占库存」参与同一全局事务（本地可见 `undo_log`） |
| Vue 3 + Vite + Element Plus | 管理台风格订单列表、购物车、结算、订单详情 |

## 后端包结构（按领域划分）

根包：`com.example.trade`

| 包路径 | 职责（概念上的「中心」） |
|--------|-------------------------|
| `common` | 统一响应、异常处理、CORS、MyBatis 分页、Web 限流拦截器等横切能力 |
| `order` | 订单状态机、下单、取消、超时关单、退款、订单查询与缓存 |
| `payment` | 模拟支付回调验签（HMAC-SHA256）、支付幂等落库 |
| `inventory` | 库存预占 / 释放 / 确认 / 退款入库；Redis + Lua 秒杀演示接口 |
| `product` | 演示商品列表（与库存 SKU 关联） |
| `fulfillment` | mock 物流：生成运单号并落库 |
| `mq` | RocketMQ 生产者与消费者（订单支付后异步链路） |

## 订单状态（状态机）

主流程：

`PENDING_PAY` → `PAID` → `ALLOCATING_STOCK` → `SHIPPED` → `COMPLETED`

分支：

- `PENDING_PAY` 可 **取消 / 超时** → `CANCELLED`（释放预占库存）
- `COMPLETED` 可演示 **退款** → `REFUNDING` → `REFUNDED`（库存回加）
